# v1.2.1-alpha 릴리즈 노트

## 주요 수정

- Docs 인증 실패 후 재시작 시, `processed_state`에 실패 이력만 남은 블록 단위 데이터가 중복 캐시 예열에 들어가던 버그를 수정했습니다.
- `docs` API 전송 전에 블록 캐시만 채우던 로직을 `마지막 성공 오프셋(last_byte_offset)` 기준으로 제한해, 실제 기록 성공한 블록만 다음 실행에서 재전송 대상에서 제외합니다.
- 네트워크/토큰 이슈로 실패한 파일이 재연결 후에도 제대로 재시도되도록 회귀 테스트를 추가했습니다.

## 확인

- 실패 블록이 재시작 예열에서 제외됨
- 재연결 후 동일 파일이 Docs API에 다시 1회 전송됨
