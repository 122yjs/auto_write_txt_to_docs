# Messenger Docs Auto Writer v1.0.4

[다운로드](https://github.com/122yjs/auto_write_txt_to_docs/releases/tag/v1.0.4) 부분의 `MessengerDocsAutoWriter-standalone.exe`를 받아 실행하세요. `developer_credentials.json` 파일 설정 등은 [설치 설명서](https://github.com/122yjs/auto_write_txt_to_docs)를 참고하세요.

## 🚀 주요 업데이트

사용자 경험(UX) 관련 개선 및 버그 수정이 포함되었습니다.

* **앱 종료 환경 개선**: 메뉴바 종료(혹은 X버튼 종료 후 트레이 없을 시)에서 곧장 종료되지 않고 `저장 및 종료`, `저장하지 않고 종료`, `취소`의 옵션을 선택할 수 있게 되었습니다.
* **필수 로드 모듈 실패 시 경고 배너 표시**: 실행 중 백엔드나 인증 모듈 등을 정상적으로 불러오지 못했을 때 사용자에게 시각적으로 큰 경고 배너를 나타내 오류를 빠르게 파악할 수 있도록 돕습니다.
* **초기 실행 모달 흐름 통합**: 처음 실행 시 도움말과 업데이트 알림이 순차적으로 뜨며 앱 작동을 가로막던 문제를 개선하여, 처음 실행 마법사 안에 통합/지연 표시해 UX를 단일 흐름으로 자연스럽게 만들었습니다.
* **Google 연결 상태 사전 테스트**: 앱의 감시를 시작하기 전, `[연결 테스트]` 버튼을 통해 Google Docs와 계정이 현재 잘 연결되어 있는지 미리 테스트할 수 있는 기능이 새로 추가되었습니다.

> 업데이트가 뜨지 않거나 실행 문제가 있을 때는 포터블(.zip) 버전을 압축 해제해 활용하거나 기존 캐시를 확인해 주시기 바랍니다.
